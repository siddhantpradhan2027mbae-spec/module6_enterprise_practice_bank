Module 6 Enterprise Practice Bank

Practice like it is a real job.

46 problems from banks, warehouses, hospitals, HR and e-commerce. Each one uses a Module 6 idea: classes and objects, methods, __init__ and self, inheritance, polymorphism, encapsulation and abstraction. Try it in VS Code first, then check yourself against the expected output.

Build a class (blueprint)

  1. What thing am I modelling?
  2. What does it HAVE? (attributes)
  3. What can it DO? (methods)
  4. What must be set up at creation? (__init__)

Reuse (inheritance, polymorphism)

  • Is it an IS-A, or does it just HAVE one?
  • What stays the same, what changes?
  • Which class answers when I call this method?

Protect (encapsulation, abstraction)

  1. Which data must never be changed directly?
  2. Which door is allowed to change it?
  3. What must every child class promise to provide?
Stuck? Grab a paper and draw one box per object. Write its attributes inside the box. After every line of code, update the boxes. Most bugs show up the moment you see which box actually changed.
